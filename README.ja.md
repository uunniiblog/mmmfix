# My Merry May With be Fix

**[English README](README.md)**

『My Merry May With be』PC版向けの実験的な64ビット `dinput8.dll` プロキシです。ゲーム本来の4:3表示を復元し、PC版で不足している操作性や表示機能を補います。

リマスター版ではCGや背景の多くが16:9表示に合わせて大きくクロップされていますが、元の4:3画像はゲーム内に残っています。このFixはD3D11のテクスチャと描画状態を調べ、元画像を使った描画を識別して4:3表示に戻します。設定用INIファイルと、ゲーム中に操作できるオーバーレイが付属します。

主な機能：

- **オーバーレイ**：F12で開きます。
- **表示モード**：4:3ピラーボックス表示と通常の16:9表示を切り替えます。
- **ADVテキストボックス**：透明度と色を調整できます。
- **キャラクターのバー越し表示**：4:3表示時にキャラクター立ち絵を黒帯の上にも表示し、ワイド画面用の追加部分を残せます。
- **ボイス再生中の文字速度**：ボイスに合わせて遅くなる文字表示速度を、通常の設定速度に合わせられます。
- **ボイス継続**：次のボイス付き台詞が始まるまで、台詞を進めても現在のボイスを再生し続けます。
- **高解像度レンダリング**：テキストやUIなどを、1080pではなくモニター解像度で描画します。
- **マウスカーソル復帰**：フォーカス復帰後やキーボード入力後、マウスを動かすとゲーム独自のカーソルを復帰させます。
- **XInputコントローラー操作（任意）**：コントローラーの基本操作をゲームのDirectInputキーボード入力に変換します。
- **ADVテキスト折り返し**：長い台詞が4:3表示の黒帯にはみ出さないよう、ADV本文の折り返し幅を調整できます。

背景やCGの多くは、もともと4:3画像として収録されています。FixはD3D11のテクスチャサイズや描画順序から元の4:3画像を識別します。該当する描画には画像全体を使い、中央に4:3の表示領域を配置して左右を黒帯にします。ADV・NVLのテキストやUIも識別し、復元した表示領域に合わせて配置します。背景のない黒画面でもストーリー中の4:3レイアウトを維持し、白いストーリー背景も4:3領域内に表示します。ゲーム選択画面、既知のワイド画面メニューやシステム画面は補正対象から除外します。

## インストール

ゲームの `MyMerryMayWithbe.exe` と同じフォルダーに、次のファイルを置いてください。

- `dinput8.dll`
- `MyMerryMayFix.ini`

### Steam Proton

Steamのゲームプロパティを開き、「起動オプション」に次を設定します。

```text
WINEDLLOVERRIDES="dinput8=n,b" %command%
```

すでに `WINEDLLOVERRIDES` を別のMOD用に設定している場合は、新しい設定を追加せず、既存の値に `dinput8=n,b` を加えてください。

ゲームを起動し、**F12**でオーバーレイを開きます。**上下キー**で項目を選び、**左右キー**で値を変更します。**Escape**または**F12**で閉じます。表示モード、立ち絵表示、テキストボックスの透明度・色は `MyMerryMayFix.ini` に保存されます。

オーバーレイ表示中はキーボード、マウス、DirectInputの入力がゲームに渡らないため、設定操作でストーリーが進むのを防げます。

アンインストールする場合は、起動オプションのDLL上書きを解除し、ゲームフォルダーから `dinput8.dll` と `MyMerryMayFix.ini` を移動または削除してください。

## 表示モード

- **Off**：リマスター16:9デフォルトの表示モード。
- **4:3 pillarbox**：1920ピクセル幅の4:3背景テクスチャを検出し、クロップ済みの四角形を画像全体を使う四角形に置き換えて、中央の4:3表示領域に描画します。既知のメッセージウィンドウ用UIもこの領域内に配置します。両作品のADVパネル（`4096x460` および `4096x464`）に対応しています。NVLテキストは専用シェーダーで比率を保って内側に配置し、ADVの話者名は文字を変形させずに名前欄へ移動します。『My Merry Maybe』のNVLも、画面上部のフォント形状から判定して補正します。

セーブ／ロード、設定、ギャラリー、バックログ、タイトル／マップ、確認ダイアログなど、識別済みのシステム画面はストーリー用の補正から除外されます。トランジション、アニメーション背景、ギャラリーは実際のゲーム内での検証が十分ではないため、表示が崩れる場合があります。

左右の黒帯は常に黒色です。

## ADVテキストボックスの見た目

オーバーレイでADVテキストボックスの透明度とRGB色を変更できます。透明度は0～200%で、100%が元の画像のアルファ値です。色を白以外にすると、元の明暗グラデーションを保ちながら色味を変更します。`255,255,255` は元のティール色をそのまま表示します。左右キーを押し続けると連続して調整できます。設定は変更時に保存されます。

```ini
[Graphics]
TextboxOpacity=100
TextboxColorR=255
TextboxColorG=255
TextboxColorB=255
HideAutoSkipButtons=0
UniformTextboxOpacity=0
```

`HideAutoSkipButtons=1` で、両作品のADV画面にあるAUTO／SKIPボタンの画像を非表示にできます。オーバーレイで実行中に切り替えられ、設定はINIに保存されます。

初期値では置き換えシェーダーは無効です。変更時もADVテキストボックスとAUTO／SKIPボタンの画像領域だけに適用されます。話者名表示、ADV本文、NVL、バックログ、システムメニューの見た目は変わりません。

一部の地の文で見える下部グラデーションも、ADVパネル画像の一部です。`UniformTextboxOpacity=1`（オーバーレイでも切り替え可能）にすると、この画像の縦方向のアルファグラデーションを均一な不透明度に置き換えます。このときスライダーの0～200は実際の不透明度0～100%に対応し、100では50%になります。パネルの透明な縁と画面切り替え時のフェードは維持します。対象は両作品のADVパネルで、NVLやその他のUI画像は変更しません。

## 立ち絵と黒帯

`SpritesOverPillarbox=1`（初期値）では、立ち絵を黒帯の上にも表示します。`0`にするか、オーバーレイの **Sprites over bars** を切り替えると、黒帯を立ち絵より手前に表示し、元の4:3版に近い見た目にします。画像データ自体を切り取ったり変更したりはしません。

```ini
[Graphics]
SpritesOverPillarbox=1
```

## ボイス再生中の文字速度

通常、ボイス付き台詞はボイスの長さに応じた文字表示時間が設定されるため、ボイスなしの台詞よりゆっくり表示されることがあります。オーバーレイの **Voiced text uses normal speed** を有効にすると、ゲーム内で設定した通常の文字速度を使います。ボイスの再生やオートモードの時間には影響しません。

```ini
[Text]
MatchVoicedTextSpeed=0
```

`1`で有効、`0`で元のボイス同期動作になります。

## ボイス継続

通常は台詞を進めるとボイスも停止します。オーバーレイの **Keep voice until next voiced line** を有効にすると、台詞送り時の停止だけを抑制し、ボイスなしの台詞が続く間も再生します。次のボイス付き台詞が始まると、ゲーム本来の再生処理で新しいボイスに切り替わります。BGMや効果音には影響しません。台詞送り以外の明示的な停止処理はそのまま動作します。

```ini
[Audio]
ContinueVoiceUntilNextVoice=1
```

## 高解像度レンダリング

ゲームは通常、シーン全体とテキストを固定サイズの1920x1080中間画像に描画してから、フルスクリーンのバックバッファーへ拡大します。この実験的な設定は、該当する中間画像とビューポートを大きくし、シーンやUIの正規化された位置を維持します。

```ini
[Rendering]
HighResolution=1
Width=0
Height=0
```

`Width=0` と `Height=0` は現在のモニター解像度を使用します。`3840` と `2160` のように両方を指定して、解像度を固定することもできます。1080pより大きな解像度でない場合は効果がありません。設定変更後はゲームを再起動してください。一部のトランジションやエフェクトは固定サイズのリソースを使う可能性があり、未検証のため実験的な機能です。

画質の向上が期待できる部分：

- 大きなフォントアトラスを高解像度で描画するADV／NVL本文、話者名、メニュー文字
- 1080pでは表現しきれない細部を含むキャラクター立ち絵の輪郭
- UI、テキストボックスの縁やグラデーションなど、高解像度のUI画像
- 拡大した中間画像に描かれるトランジションやシェーダーエフェクト
- ピラーボックスの縁や配置の精度

オーバーレイには高解像度レンダリングが有効かどうかが表示され、有効な場合は実際の内部解像度も表示されます。詳細なD3D11診断情報はログに記録されます。

Wineが予期しないモニター解像度を報告する場合は、`[Debug]` の `Logging=1` と `DisplayDiagnostics=1` を有効にして再起動してください。起動時とスワップチェーン作成時に、Win32の表示モード、ディスプレイ構成、DPI、ウィンドウサイズ、DXGI出力をログへ記録します。表示設定は変更しません。

システム確認画面の文字位置を調べるには、`[Debug]` の `SystemDialogDiagnostics=1` を有効にします。同じ画面を16:9と4:3で表示し、それぞれF12を開くと最大256回分の描画情報を記録します。画像は変更しません。

## マウスカーソルの復帰

ゲームにフォーカスを戻したときやキーボードを操作したとき、カーソルが消え、左クリックするまでゲーム内カーソルが復帰しない問題を補います。マウス移動時にゲーム独自のカーソルを復帰させ、最初のクリックが消費されるのを防ぎます。

DirectInputマウスが `DIERR_INPUTLOST` または `DIERR_NOTACQUIRED` を返した場合、ゲームが非アクティブの間は再取得を待ち、フォーカス復帰またはマウス移動時に再試行します。また、キーボードやフォーカスの変化前にゲームのカーソルを記憶し、次のマウス移動で復元します。汎用のシステム矢印カーソルには置き換えません。

```ini
[Input]
RestoreCursor=1
```

`0`にすると、この補正を無効にして元の動作に戻します。

## XInputコントローラー操作

コントローラーがXInputで認識される場合、ゲームのDirectInputキーボード入力に変換できます。次を設定し、ゲームを再起動してください。

```ini
[Input]
XInputEnabled=1
XInputNativeActions=1
```

`XInputNativeActions=1`では、同梱VDFのSteam Inputアクションをゲームへ渡します。A/B/X/Y、Start、LB/RB、方向キーはVDFの決定／戻る／オート／バックログ／メニュー／スキップ／移動に対応します。左スティックは矢印キーとして扱います。`XInputNativeActions=0`では、以下のINI設定でゲームパッドをキーボード／マウス操作に割り当てられます。ゲーム内のキーボードガイドに合わせ、初期設定は Space＝決定、X＝キャンセル／テキスト枠、G＝オート、2＝バックログ、1＝システムメニュー、Q＝強制スキップ、E＝スキップモード、R＝クイックセーブ、F＝クイックロードです。初期設定ではLT/RTをクイックセーブ／ロードに割り当てています。`NONE`で無効化でき、`RIGHTMOUSE`または`LEFTMOUSE`でマウスボタンも送れます。例えばBをXキーにするには `B=X` とします。

```ini
[Input]
XInputEnabled=1
XInputNativeActions=0

[Controller]
A=SPACE
B=RIGHTMOUSE
X=G
Y=2
Start=1
Back=X
LB=Q
RB=E
LT=R
RT=F
L3=NONE
R3=NONE
Up=UP
Down=DOWN
Right=RIGHT
Left=LEFT
```

設定はゲーム起動時に読み込みます。ネイティブアクション使用中もLT/RT/L3/R3の追加割り当ては使えます。通常のキーボード操作はそのまま使えます。オーバーレイ表示中とゲームが非アクティブな間はコントローラー入力を渡しません。WindowsとProtonの両方で使用できますが、コントローラーがXInputに表示される必要があります。`Logging=1`と`ControllerDiagnostics=1`で認識状況をログに記録できます。

## ADVの実験的な折り返し

WindowsとProtonのオーバーレイでADVの折り返しをオン／オフにし、行幅を実行中に変更できます。変更は `[ExperimentalWrapping]` に保存され、次の台詞から適用されます。表示中の文章は再配置されません。左右キーを押し続けると5単位ずつ、Shift＋左右キーでは1単位ずつ調整できます。オーバーレイで選べる幅は800～1420です。NVL、バックログ、話者名、メニューなどの幅は変更しません。INIを直接編集した場合は再起動が必要です。

```ini
[ExperimentalWrapping]
Enabled=1
Width=1320
```

クラッシュを調べる場合は `[Debug]` の `Logging=1` と `WrappingDiagnostics=1` を設定して再起動してください。ADVの折り返し呼び出しと、該当するクラッシュ時の文字位置・行幅の状態をログに記録します。

## オーバーレイのショートカット

ゲームを終了してから `MyMerryMayFix.ini` を編集します。

```ini
[Overlay]
Hotkey=F12
```

`F1`～`F12`、`INSERT`、`HOME`、`END`、`DELETE`を指定できます。

## ログと問題報告

`MyMerryMayFix.log` はDLLと同じフォルダーに作成されます。問題を報告する際は、このログと、ストーリーモードおよびギャラリーモードでオーバーレイを表示したスクリーンショットを添付してください。背景判定の問題では、トランジション中ではなく、対象のCGが安定して表示されているときの画像が役立ちます。

オーバーレイはキーボード操作を使用します。

## Linuxでビルド

必要なもの：CMake、Ninja、64ビットMinGW-w64 C++コンパイラー。

```sh
cmake -S . -B build-mingw -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_TOOLCHAIN_FILE=cmake/mingw64.cmake
cmake --build build-mingw
```

生成されたDLLは `build-mingw/dinput8.dll` です。サードパーティーのソースコードはダウンロードせず、オーバーレイの文字描画にはD3D11と小さなGDIテクスチャを使用します。
